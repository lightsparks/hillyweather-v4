# HillyWeather App v4 🌦️
HillyWeather App is a simple weather application built with Vue 3 and Vite, designed as a learning project to explore modern front-end development best practices. The app retrieves current weather data using the OpenWeather One Call API 3.0 and the Geocoding API to convert city names into coordinates.

## Features
Search weather by city name
Get real-time weather data (temperature, humidity, wind, and description)
Built with component-based architecture
Uses TypeScript for type safety
Environment-based API key management
Clean and maintainable file structure

## Tech Stack
* [Vue 3](https://vuejs.org/)
* [Vite](https://vitejs.dev/)
* [TypeScript](https://www.typescriptlang.org/)
* [OpenWeatherMap API](https://openweathermap.org/api)

## Status
This project is under active development as a personal learning exercise to improve frontend architecture, API integration, and coding best practices.

## Environment Setup
1. Copy `.env.example` to `.env.local`
2. Fill in your `VITE_OPENWEATHER_API_KEY` and other vars
3. `npm install && npm run dev`
